The objective of this project is to:

Identify employee attrition patterns

Analyze workforce distribution and department performance

Track employee satisfaction, salary trends & work-life balance

Help HR teams take data-driven decisions

Build multiple dashboards using Excel, SQL, Power BI & Tableau
